# Ilha dos Desesperados

Protótipo inicial de um jogo 2D de sobrevivência e gerenciamento, feito em Godot 4.

## O que já funciona nesta versão
- Menu inicial.
- Tela de acampamento com três sobreviventes.
- Indicadores de fome, sede e energia.
- Recursos: água, comida, madeira e pedra.
- Atribuição de tarefas individuais.
- Expedição simples com recompensa aleatória.
- Passagem de dia, consumo de recursos e eventos aleatórios.

## Como abrir no Windows
1. Instale o Godot 4 (versão 4.3 ou superior).
2. Extraia a pasta do projeto.
3. Abra o Godot e escolha **Importar**.
4. Selecione o arquivo `project.godot` desta pasta.
5. Pressione F6 ou F5 para executar.

## Observações
Esta é uma versão de protótipo: ainda não possui arte final, salvamento, construção de edifícios, mapa de exploração ou exportação Android configurada. Esses recursos serão adicionados nas próximas etapas.
